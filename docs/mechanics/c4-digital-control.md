# Lab C4 — 數位實作：取樣、量化、延遲、雜訊（銜接實體倒立擺）

> Part C — 控制（補充）｜[教材目錄](README.md)｜[章節對照總表](README.md#1-章節對照總表)

**學習目標**：把「理想連續時間控制器」換成「在 MCU 上跑的控制器」，並量化各種非理想因素的影響，作為選擇硬體規格的依據。

**核心觀念**：
- **離散化**：控制器以週期 $T_s$ 執行，輸出以零階保持（ZOH）維持到下一次更新。用 `cont2discrete` 得到 $(A_d,B_d)$，再解 discrete ARE 得到離散 LQR。取樣變慢時，它比直接沿用連續增益更耐用；本例在 45 Hz 時只有離散設計能穩住。
- **只量得到位置**：編碼器有量化誤差（本例 4096 cpr），速度必須自己差分並低通濾波。這等於加入了相位延遲。
- **延遲**：運算和通訊延遲會吃掉相位裕度。同樣是 40 Hz，加 1 拍延遲就失穩，不加延遲則可以穩住。
- 本模型在 200 Hz 下可以容忍約 35 ms（7 拍）的延遲；量測雜訊會讓穩態角度的抖動放大約 6 倍。

**程式碼**：[`labC4_digital_control.py`](../../m1-inverted-pendulum/sim/mechanics-labs/labC4_digital_control.py)　｜　執行：`python labC4_digital_control.py`

**預期輸出**
```
 f_ctrl | 離散LQR | 連續K直接用
  500 Hz |  OK    |   OK 
  200 Hz |  OK    |   OK 
  100 Hz |  OK    |   OK 
   50 Hz |  OK    |   OK 
   45 Hz |  OK    |   FAIL
   40 Hz |  FAIL   |   FAIL
[PASS] 200 Hz 以上兩種設計都能穩住
[PASS] 取樣變慢時，離散化設計的容忍度 ≥ 直接沿用連續增益
[PASS] 45 Hz：離散 LQR 仍穩、直接沿用連續 K 已失敗
[PASS] 40 Hz + 1 拍延遲 → 兩者都失敗：取樣率是硬體規格，不是細節
[PASS] 同樣 40 Hz 但沒有延遲 → 離散 LQR 可以穩住（延遲吃掉了相位裕度）
200 Hz 下可容忍的延遲 ≈ 7 拍 = 35 ms（再多就失穩）
[PASS] 延遲預算有限：數十 ms 等級
量測雜訊 σ=0e+00：穩定，穩態 θ RMS = 5.4e-04 rad
量測雜訊 σ=2e-03：穩定，穩態 θ RMS = 3.3e-03 rad
[PASS] 加入雜訊仍穩定，但穩態抖動變大
```

> **注意**：延遲掃描的邊界是「臨界」的：延遲 8 拍時，編碼器量化加延遲會形成振幅約 0.021 rad 的極限環，剛好落在 `trial()` 的 0.02 rad 門檻上；延遲 7 拍時振幅只有約 0.002 rad。因此不同平台的浮點細節可能讓最後一行印出 8 拍，這不代表程式有錯。
>
> **注意**：上面的臨界值（45 Hz、35 ms）只適用於本模型參數。倒立點不穩定極點約為 5.6 rad/s，對應時間常數約 0.18 s。擺桿越短，不穩定極點越快，所需的取樣率和延遲預算就越嚴格。實際選硬體時，請代入自己擺桿的參數重跑。一般經驗法則是取樣頻率至少為閉迴路頻寬的 10–20 倍，但這只是經驗，請以模擬掃描為準。

**延伸練習**：把差分加低通的速度估測換成 Kalman 濾波器（Tedrake Ch19 State Estimation），比較在相同雜訊下的穩態抖動。
